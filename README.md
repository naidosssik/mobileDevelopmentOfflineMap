# mobileDevelopmentTenVariant

## Касумова Наида Рашидовна
## группа 231-323

Проект: мобильное приложение "Карта с точками и оффлайн-режим"

Критерии: 
- Файлы изображения получаем через командную строку или потом можно выбрать с другой по горячей клавише. 
- Тайлы скачиваем с Яндекс или OpenSteepMap. 
- Точки получаем с GPS, координат фотографий или добавляем руками. 
- Навигация. 
- Результат примерно как обычные Яндекс.Карты, но с точками и режимом офлайн.
